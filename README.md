README
Bank Account Management System
A simple console application in Python for managing bank accounts.
Features
• Create account
• Check balance
• Deposit money
• Withdraw money
• Display all accounts
• Input validation for amounts and account lookup
Requirements
• Python 3.6 or higher
• No external libraries needed
How to Run
1. Extract the zip and open a terminal in the folder.
2. Run: python bank_account_system.py
3. Follow the on-screen menu.
Option Action
1 Create Account
2 Check Balance
3 Deposit Money
4 Withdraw Money
5 Display All Accounts
6 Exit
Menu Options
Sample Usage
Enter your choice: 1
Enter account number: 101
Enter account holder name: Amit
Enter initial deposit: 5000
Account created successfully!
Notes
• Data is stored in memory and is not saved after exit.
• Entering non-numeric text for an amount will raise an error (see Report for suggested
improvements).
